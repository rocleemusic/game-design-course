§4

Buttons

shape/behavior = shipped dialogue pills · color = mockup gold

Two dark-surface families lifted structurally from DialogueSystem.ts's choice pills and control pills — same fill/border/radius math, recolored. A third, on-canvas family covers buttons that sit on parchment, which the dialogue system never needed.

PRIMARY PILL — radius 18% of height — display font — e.g. "Cast", "Resume"
  • fill panel #241c14 @94% → hover panelHover #2f2519 @94%
  • border 2px gold @55% → hover goldBright @55%
  • text cream (enabled) / dim (disabled)
UTILITY PILL — radius 30% of height — mono font — HUD chrome, footer actions, Auto/Skip/Log
  • fill night #14110c @90% → hover/active panelHover @90%
  • border 2px gold @35% → hover/active goldBright @90%
  • text gold → hover/active goldBright
ON-CANVAS BUTTON — new, for parchment surfaces (no dialogue equivalent)
  • fill transparent → hover gold @18–34%
  • border 1px stitch → hover gold
  • text ink, mono · warn modifier: text rust, hover border rustBright
