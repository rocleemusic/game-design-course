The brief

Two questions, one run

The GDD claims a dev crew of isolated AI agents can generate narrative content that holds together. That claim had never been run — only described. This proof answers the two questions that decide whether it survives contact with production.

Does it work?

Can six specialised agents produce a character a human would actually ship, while obeying the architecture: call down, signal up, no worker-to-worker calls, and a human gate that nothing bypasses?

What does it cost?

The GDD budgets 2M tokens for the crew. Until this run that number had nothing under it. Every figure here exists to put the budget on measured ground.

Phase 1 benchmarked five model configurations against a blind human read. Phase 2 ran the full pipeline live at the winning configuration.

2
Method

Why the read was blind

The GDD sets the acceptance bar as a human judgement: agent-generated lines pass the side-by-side distinctness read. A judgement like that is worthless if the judge knows which model produced which output — "this one is the expensive model" contaminates the read before it starts.

So the five outputs were stripped of model identity and re-randomized: the benchmark plan itself named the models against labels A1…B3, so those labels were replaced with opaque ones before anything reached a human. The ranking was recorded first. The reveal, the flag counts, and the token figures were all withheld until after.

The surprise: the prose-tuned model won the anti-ornamental voice

The register is deliberately flat — one clause, no amplification, "cut before adding." The expectation was that a model tuned toward rich prose would fight it. It didn't; it won outright. The likely reason is that holding a flat register is a prose skill: knowing where the weight lands in a short clause. Restraint was never the hard part. Cadence was.

Here the human read and the automated check disagreed, and the check won. The preferred card's three personality axes were not independent — two of them encoded the same fact, so knowing one predicted the other. That is the exact failure that makes a generated cast read as one character in different hats.

The two objections were different in kind. Verbosity is presentation — one sentence in a prompt fixes it. Correlated axes are structural — the defect propagates into every line written from that card and into every soul built the same way. Opus took the slot with a word cap attached.

Honest limit: on cost the two arms disagree depending on which measure you use, and the difference traces to turn count on a single sample. The cost question is open; the decision rests on the structural defect alone.

The architecture held

Seventeen agent calls, four roles, three human gates. The architectural claims were checked against the run rather than asserted.

// one call-down / signal-up pair, verbatim shape
orchestrator → architect  { arc_doc, soul_seed, scene_context, schemas }
architect    → orchestrator { persona_card, echo_templates, delta_rule, canon_flags }
orchestrator → verifier   { batch, active_canon, arc_doc, invariants }
verifier     → orchestrator { verification_report[], human_action_required, summary }
// no edge from architect to verifier. there is no such edge in the system.

The architecture is not what strained. Revision governance is. The persona card was approved in full, unchanged, on the first attempt. The cost came from everything after.

The number

What a soul costs

Every call in Phase 2 was a single turn with no file reads, because the orchestrator handed each worker its material directly instead of making it fetch. That one change cut billed volume 6.9× against Phase 1.

The token budget binds long before the money does

Eight cards plus fifteen soul-appearances comes to roughly $26 at run cost — about $100 if revisions run at the rate this project measured. The same work is a hard ceiling in tokens and a bar tab in dollars.

So the budget is protecting capacity, not spend — which means model choices should be made on quality, with cost as the tiebreak. Every decision in this report already follows that order; the numbers are what justify it.

What the 2M crew budget actually buys

remaining  2,000,000 − 410,872 = 1,589,128

The slice runs five days × three time-blocks = 15 scene-slots. So the budget affords roughly one soul-appearance per time-block across the entire festival week — with zero revisions.

And revisions are the real cost

Revisions cost 3.8× the generation they corrected. A 500K revision reserve covers roughly two scenes out of fifteen at that rate. Capping revisions bounds the damage; it does not prevent it.

Why revisions happened, and the one lever that stops them

Four separate times, the content agent was told to fix one thing — and fixed it while silently spending a different constraint.

Told to fixSilently lost
an invented factthe soul's signature
flowthe echo's canon
warmththe refusal
self-narrationthe offer's target

The only pass that traded nothing away was the one where the entire constraint set was restated alongside the defect. A revision brief that names only the problem is an instruction to trade something else for it — so briefing quality, not the revision cap, is what makes the roster affordable.

Limits

What this run does not prove

  • One soul, one scene. Every model comparison is n=1. Arms that landed close are inconclusive, not equal.
  • One line is still unwritten. The receive-beat — the beat the Giver's whole arc turns on — is deferred, because it turned out to need player choice and the schema cannot express a branch. A gap in the specification, found by running it.
  • The orchestrator's own cost is invisible. It is the main session's reasoning and appears in no figure here. Every per-soul number is a floor, not a ceiling.
  • The scene model is assumed. One content call, one soul, one time-block. If scenes routinely carry several souls, the affordable count moves.
